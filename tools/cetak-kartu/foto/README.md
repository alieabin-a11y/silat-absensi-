# Direktori Foto Siswa

Folder ini digunakan untuk menyimpan foto siswa yang akan dicetak pada kartu anggota.

## Format Penamaan File:
Simpan foto dengan nama file sesuai **ID Siswa** (format `.jpg` atau `.png`):
- `S001.jpg` atau `S001.png`
- `S002.jpg` atau `S002.png`
- `S003.jpg` atau `S003.png`
- dst sampai `S036.jpg`

## Rekomendasi Foto:
- Rasio foto: **3 : 4** (portrait / setengah badan)
- Latar belakang: Polos / transparan / seragam silat
- Resolusi minimal: **600 x 800 px** agar hasil cetak tajam

*Jika ada siswa yang belum memiliki file foto di folder ini, generator akan otomatis menggunakan siluet/avatar default silat.*
